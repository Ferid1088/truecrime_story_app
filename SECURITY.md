# Security policy

TrueCrime Story Studio is operated by one person. To report a vulnerability, open a private security advisory on GitHub (Security tab, "Report a vulnerability") or email the repository owner. Please do not open a public issue. Expect an answer within a few days.

How the application protects itself, and how to run it safely, is described in `docs/security.md`. Dependencies are audited on every push and weekly (see `docs/release.md`).
