# Stage-control UI captures

These screenshots are generated by `frontend/e2e/stage-control.spec.ts` against
the no-network isolated fixture:

- `stage-control-desktop.png` — stage list and language filter at desktop width.
- `stage-control-phone.png` — the same flow at 390px phone width.

The preview dialog and apply result are exercised by the same Playwright suite;
the screenshots capture the stage-list state so the layout can be reviewed
without opening a live job.
