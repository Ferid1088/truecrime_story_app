## Self-review of the diff

- `app/core/ai_config.py`, `config/parameters/detective_board.json`: new config, follows `FillWaysConfig`/`CoverageConfig` pattern exactly; loads cleanly (checked by import).
- `app/db/models.py` + `migrations/versions/0049_board_plans.py`: additive only, mirrors `ChapterPlan`/migration `0048`; applied and verified on live Postgres.
- `app/documentary/detective_board.py`: pure, deterministic, no provider calls; the only non-obvious choice is that a beat produces **at most one** card (a dated-event beat that is also a contradiction beat gets the dated-event card, never two) — deliberate, to avoid double-carding one moment.
- `app/agents/detective_board.py`: one writer call per language as specified (no auditor call, unlike chapters — the spec only asked for "a writer agent", and a deterministic word-count fallback (truncating the card's own claim) replaces any title that fails the cap, so a card is never silently dropped for a writer problem).
- `app/documentary/render/cards.py` (`DetectiveBoardCard`), `render/engine.py`, `production/script.py` (`insert_detective_board_cards`, `CARD_KINDS`): additive; existing chapter/timeline card paths untouched (ran their tests, all green).
- `app/documentary/production/script.py:compose`/`build_production_script`: new optional `board=` parameter, defaults preserve old behaviour when absent.
- `app/documentary/jobs.py`: new optional `board_plan` stage, mirrors `chapters()`; skipped cleanly when `detective_board.enabled` is false.

## What remains unproven

- **No full end-to-end film render was done** (compose → render engine → encoded mp4 for an actual case-8 film). The live proof covers the real data path (blueprint → selection → writer → DB) and the real rendering code (stills + a clip) from that real data, but not the full pipeline wired together end to end — that run was not attempted (time/scope), and I did not watch a complete film with the board in it.
- The fallback title-truncation can read awkwardly when it cuts mid-clause: case 8's real card2 came back from the writer over the 5-word cap and fell back to "Adelaide Churchill saw Lizzie at" (a dangling preposition). The cap is enforced correctly; the fallback's *wording quality* is not polished.
- B9 (share-of-film-time cap, no-identical-look-twice) is only partially wired: the config fields exist but nothing yet checks the board's total screen time against `max_share`, and there is only ever one visual "look" for the board, so "never identical twice in a row" has no real alternative look to violate — this should be revisited once the board is used inside a real multi-board film.
- B8's "renderer failure is never silent" is only proven for the *no-titles* / disabled paths, not for an actual exception raised inside `DetectiveBoardCard` during a real render (no fault-injection test was written for that).
- Visual density/contrast of the kind-colour stripe was eyeballed on one still (`board_still_3.png`) only; not checked at 9:16 crop, nor for every kind colour, nor under a formal contrast-ratio check (unlike the cover-label work referenced in the owner's shorts task).
- RTL title *shaping* (raqm) is trusted from `typography.py`'s own existing tests, not independently re-rendered here with real Persian/Arabic case-8 titles (no fa/ar `BoardWriter` call was made — English only, per the owner's instruction to not run other languages before they're watched).
- Contradiction/explains **links** are deterministic but based on a narrow heuristic (`relies_on` pointing at an earlier dated event); richer real cases may have contradictions that this heuristic does not connect.
