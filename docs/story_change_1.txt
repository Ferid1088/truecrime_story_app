THE PIPELINE
Shared inputs, built once per case and used by every language: the story plan
(acts, purposes, reveal order, do_not_reveal; language-neutral), the promoted
facts, timeline, contradictions and claims from ALL sources with their source
ids (video-backed facts first, contradictions never dropped), and the
originality rules.

 STAGE 1  (ONCE per case) draft_writer: Sonnet 5.5 (alias premium) receives ALL
          texts, acts and evidence (no 100-fact cap here: config
          story_quality.max_evidence_for_long_draft, none by default) plus the
          English style guide, and writes ONE 90-minute story in ENGLISH.
          Config: story_pipeline.draft_language = "en", long_draft_minutes = 90
          (the validator rejects a draft shorter than the final range).

 Then, FOR EACH language (fa, en, de, ar), independently and in parallel
 (concurrency from config):

 STAGE 2  rewrite_writer: GPT 6.1 Sol, high thinking, receives the English draft,
          the plan and the 100-fact evidence pack, and writes the film text
          NATIVELY in the target language for about 60 to 70 minutes (requested
          minutes default 60 plus rewrite_headroom_minutes 10; a custom request
          shifts the range). It re-tells in the language's own storytelling and
          spoken register; it never translates sentence by sentence. For en it
          rewrites the English draft to the shorter length in the same language.

 STAGE 3  inspector: GPT 6.1 Sol, high thinking, a SEPARATE agent (own prompt,
          fresh context, it never sees stage 2's reasoning) criticizes the
          stage-2 text IN THE TARGET LANGUAGE: native wording, spoken register,
          repetition, reveal timing, unsupported claims, source commentary,
          tension, length. Its input is the stage-2 text, the plan and a compact
          evidence list (id + claim + uncertainty flag), not the full pack.
          Output: structured, actionable items.

 STAGE 4  final_writer: GPT 6.1 Sol, high thinking, receives the stage-2 text (the
          last version) + the stage-3 critique (+ the evidence pack) and writes
          the FINAL text of that language.

After stage 4 the deterministic gates run on each final text: grounding against
the evidence, consistency, length tolerance, figures/names check against the
evidence, reveal-order check against the plan, originality guard against the
research transcripts. A gate failure returns to STAGE 4 only, bounded by config.

CROSS-LANGUAGE FACTS CHECK (replaces the old semantic check against a master):
a deterministic report compares the four final texts: dates, numbers, named
persons and places, and which evidence ids each act uses. Any mismatch between
languages is listed and fails the gate. No language is the reference.

The draft (stage 1) is stored once as a shared version. Every language version
records which draft it derives from (draft id, draft language, prompt sha256),
so the UI and the API never present a language as independent of the draft.
Expected large calls per case: 1 draft + 4 x 3 Sol = 13; report the real count.
