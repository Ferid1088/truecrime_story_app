## Ignored-input summary

The Phase 2 work must make every fake output a deterministic function of its
complete request payload. The concrete ignored inputs found in this inventory
are:

* Generation: system prompt, role/model routing, generation parameters/config,
  attachments/images, and most user payload fields for fixed scripted roles;
  spoken and host fakes also ignore most prompt metadata and source wording.
* TTS: every `VoiceRequest` field except text length; generated audio does not
  encode text content, voice/model/settings, context, seed, or language.
* ASR: audio bytes, requested language, and provider/configuration; it trusts a
  sidecar JSON instead.
* Music: prompt, influence, and provider/library configuration.
* Visual search: all queries except the first entity assertion, language,
  provider selection/configuration, and source response data.
* Geocoding: proximity (`near`), client/configuration, and provider response.
* Map rendering: coordinates, zoom, client/configuration, and map tile data.
* FFmpeg is real and therefore has no mock input omission in this pipeline.

These are inventory findings only. No artifact type is promoted to `SOUND` by
this document or by registry/hash checks; the snapshot-diff harness remains the
only permitted source of soundness status (`app/services/soundness.py:18-41`).
